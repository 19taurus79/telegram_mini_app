# Project Rules

## TypeScript Code Quality
- **Запрет на `any`**: Никогда не использовать тип `any` в TypeScript коде проекта. Всегда объявлять точные интерфейсы, типы или при необходимости использовать `unknown`.

## React & UI Rendering
- **React-Leaflet в условном рендеринге**: Leaflet рассчитывает размеры контейнера только один раз при инициализации. При рендеринге `MapContainer` внутри flex/grid-контейнеров, которые появляются динамически (conditional rendering), **всегда** добавляйте компонент-инвалидатор, который вызывает `map.invalidateSize()` через таймауты. Без этого координаты карты смещаются, и клики по полигонам/маркерам не работают, пока окно браузера не изменит размер.
- **Предотвращение бесконечных циклов**: При передаче коллбэков в компоненты карт (или другие тяжелые компоненты, которые используют их в `useEffect`), **всегда** используйте `useCallback` со стабильными зависимостями. Никогда не передавайте инлайн-функции `() => {}`, так как это создает новую ссылку при каждом рендере и может вызвать `Infinite Render Loop`, если дочерний компонент обновляет родительский стейт.
- **react-grid-layout**: Не используйте вложенные сетки `react-grid-layout` с `WidthProvider` друг в друге. Это приводит к расчету нулевой высоты. Предпочитайте CSS Flexbox для внутренней верстки компонентов (например, сайдбаров или панелей деталей), оставляя `react-grid-layout` только для корневого дашборда.
